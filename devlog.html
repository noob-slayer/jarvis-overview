Dev log

What actually changed, in order.

No roadmap, no marketing copy — just what shipped, when, and why. Updated as changes land.

17 Aug 2026
Fix

Pomodoro and the time-use check-in no longer double-count

The Pomodoro timer and the every-two-hours "what were you up to" Telegram check-in both log to the same time-use record, but had no awareness of each other — a Pomodoro running during a check-in window didn't stop the check-in from offering to log that same stretch of time again. Now each check-in looks up how much of its window a finished Pomodoro already covered and shrinks the duration buttons it offers accordingly (so a 25-minute Pomodoro in a 2-hour window leaves buttons for the remaining 95 minutes, not the full 120), and says so directly in the message. Not a hard block — the smallest option always stays available — just no easy way to accidentally log the same minutes twice.

17 Aug 2026
New tool

Pomodoro focus timer

Start a focus session over Telegram — default 25 minutes, the classic Pomodoro length, but any duration works. When it ends, J.A.R.V.I.S sends a message and automatically logs the session to the time-use activity log, so focused work shows up in the existing daily time breakdown without typing it in twice. Built on the same scheduling system reminders already use (APScheduler), just one-shot instead of recurring. Can be stopped early too — the partial time still gets logged rather than thrown away.

17 Aug 2026
SecurityFix

Reliability pass

Closed a gap in the web dashboard's login: if a username was set but the password was left blank, it would accept the blank password instead of rejecting it. Fixed a bug where asking to delete two to-dos in one message could silently lose the first one — both are now confirmed and deleted independently, not just the last one requested. And fixed a bug that had made set_todo_quadrant — the command that sorts a to-do into an urgent/important priority quadrant — completely unreachable from chat, even though it existed in the code.

17 Aug 2026
Fix

Fixed multi-turn tool routing

Short follow-up questions like "what's its rating" could lose track of what was just being discussed a couple of messages earlier — J.A.R.V.I.S would wrongly claim it had no way to look something up, even though it just had the means to. It now keeps a little more recent conversation in mind when deciding which of its tools a message might need, so short follow-ups stay connected to whatever came right before them.

17 Aug 2026
New tool

Restaurant & cafe recommendations

food_roulette — pulls live restaurant and cafe listings from Google Places, then has Claude weigh rating, price, and cuisine fit to make one genuine recommendation, not a random pick off the list.

17 Aug 2026
New tool

Flight price search

search_flights — real one-way airfares, ranked by price, whether a nonstop flight was asked for, and a time-of-day window given in the request, then checked against the calendar for conflicts on the travel date.

17 Aug 2026
Docs

Reconciled voice docs with reality

The always-on voice listener — it hears "hey J.A.R.V.I.S." and starts a conversation, the same idea as Alexa or Siri's wake word — and a local check that verifies it's actually Siddharth's voice before responding, had both quietly shipped without the internal documentation catching up. The docs previously still said voice verification was skipped on purpose; they now describe what's actually running.

7 Jul 2026
Fix

Stability: three rounds in one day

Tracked down the real causes behind a string of crashes and unnecessary automatic restarts. Scheduled background jobs were making slow network calls (to Google Sheets and Garmin) in a way that froze the whole app instead of running quietly in the background; two tools were sharing one connection to Google Sheets in a way that isn't safe to do from multiple places at once, which caused rare but real native crashes (an OpenSSL thread-safety issue, for the record); and an earlier same-day fix had accidentally broken Sheets access entirely by targeting the wrong version of a library. Also simplified how scheduled jobs are configured, added a similar safety lock around calendar access, and changed the automatic health check to test a lightweight internal signal (/ping) instead of the full dashboard — so a slow response from an external service like Google Sheets can no longer get a perfectly healthy J.A.R.V.I.S. killed and restarted by mistake.

16 Jun 2026
Fix

Fixed native crashes and false-alarm restarts

Traced a set of hard crashes to two parts of the app sharing one network connection at the same moment, and fixed it by making sure only one request goes out over that connection at a time. The automatic health check also got more patient — it now waits for three slow responses in a row, not just one, before deciding something's actually wrong and restarting the app.

15 Jun 2026
New

Time-use tracking + dashboard rework

Added time-use tracking — a Telegram prompt every two hours asking what you'd just been doing, logging exact durations per category and labeling each as productive, neutral, or a time sink. The dashboard's calendar tile was swapped for a custom-drawn donut chart (hand-built, not from a charting library) showing the day's time breakdown at a glance, alongside a run of smaller layout and caching fixes.

14 Jun 2026
Security

Security and cleanup pass

A security-focused review across the codebase, with unused code removed along the way.

3 Jun 2026
New

Marathon coach, Strava, and voice sessions

Connected directly to Strava's own API, after confirming that Strava's newer AI-assistant connector (MCP, the same kind of protocol Claude uses to plug into external tools) only works from inside chat apps like Claude's own interface — not from an independent backend like this one. That feeds two new coaching jobs: a daily recovery check and a weekly training plan, both combining Garmin's recovery data (sleep, heart-rate variability) with Strava's record of actual training done. Also shipped the first voice feature — trigger it over Telegram, and it listens through the laptop's microphone and replies out loud.

20 May 2026
New

Birthdays

Add, list, and remove birthdays, with a morning heads-up for anything coming up in the next three days.

5 May 2026
New

Reminders, personality profiles, and auto-sleep

Reminders became their own feature — scheduled Telegram notifications for any time you choose, kept deliberately separate from the to-do list. Sleep now logs itself automatically every day straight from Garmin, no manual entry needed. Also added switchable personalities — J.A.R.V.I.S can take on different named personas instead of one fixed voice — plus a safety net (a fixed fallback list of tools, FALLBACK_GROUPS) so a short reply like "yes" never accidentally loses access to whatever it was replying to.

17 Apr 2026
New

Tiered routing + learning tools

Introduced tiered routing: a cheaper, faster AI model (Claude Haiku) quickly figures out what a message is actually about — expenses, fitness, weather, whichever — before handing off to the more capable model (Claude Sonnet) that handles it, cutting the cost of each message by roughly 60%. Alongside it: spaced-repetition vocabulary quizzes (recently-missed words come back around sooner than ones you know well), a weekly summary, a running projection of whether the month's spending is on pace, daily goals, and the ability to send voice messages instead of typing.

15 Apr 2026
New

Media library, life log, and self-portraits

A media library for logging and rating what's watched, auto-filling details like year and genre, plus a one-time import of an existing IMDb watch history. Alongside it, a seven-part life log covering food, sleep, social interactions, ideas, decisions, energy levels, and reading. And an on-demand "self-portrait" generator that summarizes patterns across all of that data — each run is saved as its own dated version instead of overwriting the last one, it deliberately avoids personality-typing language (no MBTI, no Big Five labels), and it skips any section it doesn't have enough real data to say something meaningful about, rather than guessing. Same day: calorie math changed to count resting-metabolism calories (BMR) plus activity calories burned, not activity alone.

14 Apr 2026
Fix

Sharper budgets and a real conversation-memory bug

Per-category budget limits got more precise, habits gained weekly totals, running AI cost got its own small trend chart, and mood-pattern analysis shipped — deliberately built as simple side-by-side comparisons rather than statistical correlations, so it never implies more precision than a small amount of personal data can actually support. Also fixed a real bug: a leftover, half-recorded action from earlier in a conversation could crash the connection to Claude outright in certain cases. That's now detected and cleaned up automatically before it causes a problem.

14 Apr 2026
New

Dashboard v3

A full redesign of the live dashboard — a calendar sidebar, a weather widget, seven-day trend charts for sleep, heart-rate variability, Garmin's energy-level score ("body battery"), and running distance, a GitHub-style grid of daily habit streaks, a mood trend line, and spending progress bars. Every chart was hand-built rather than pulled from a charting library. Shipped alongside a same-day fix after the trends row started stretching the page taller with no limit.

14 Apr 2026
NewFix

Quotes, dinner roulette, and a real tool-memory bug

Added a literature-quotes feature (44 curated public-domain excerpts) and dinner_roulette — a random pick from a curated list of How I Met Your Mother episodes (73 of them, at the time) for something to watch over dinner — merged into one 6PM message instead of two separate notifications. Right behind it, a genuine bug fix: J.A.R.V.I.S had been forgetting exactly what actions it had already taken earlier in a conversation, which meant it would sometimes repeat something it had just done. It now keeps a proper record of completed actions and their results, not just a rendered text summary of them.

14 Apr 2026
NewFix

Scheduler, Garmin, and the first real cost cut

The whole scheduled-jobs system landed (built on APScheduler) — a morning briefing, an evening summary, habit reminders, and a weekly study check-in — alongside Garmin fitness syncing and a study-progress tracker. Also fixed a real bug in habit logging: it had been silently treating each day as a single slot, so a second workout on the same day just overwrote the first instead of adding to it — every entry is kept now. And the amount of past conversation J.A.R.V.I.S re-reads on every message was cut from 20 messages down to 5, cutting the cost of each message by roughly 45%.

Restart

A deliberate restart

The project picked back up from a much smaller starting point than where it had been a month earlier (see below) — running on Claude, reachable only through Telegram, living only on a laptop: just the core AI conversation loop, expense tracking into a spreadsheet, and a bare-bones dashboard. What exactly prompted scaling back this far isn't recorded anywhere that survived — but the file history makes clear it was a deliberate, clean restart, not a gradual trim.

14 Mar 2026
History

A same-evening detour to OpenAI, then back

Telegram was added alongside the original WhatsApp integration; about an hour later, the underlying AI model was swapped from Claude Opus to OpenAI's GPT-4o as a same-evening experiment. It didn't stick — every version since has run on Claude.

13 Mar 2026
History

Rebuilt from scratch, in Python

The n8n workflow below was rebuilt from the ground up as a standalone Python app — an always-on assistant meant to run continuously on a Raspberry Pi, reachable over WhatsApp via Twilio (a messaging API service), with voice wake-word detection, OpenAI's Whisper for speech-to-text, ElevenLabs for spoken voice replies, Spotify control, weather via OpenWeatherMap, web search switched from Tavily to Serper, and a Reddit research agent added on top. Built on Claude Opus from this rewrite's very first version — OpenAI only shows up once, briefly, in the entry right below this one. None of this survived the restart described above; everything from this point up the page is what actually carried through into the project as it exists today.

22–23 Dec 2025
History

Where it actually started: an n8n workflow

Before any of this was a codebase, it was a single n8n workflow — n8n is a drag-and-drop automation tool, so this was built with no code at all: a LangChain AI-agent node wired to GPT via OpenAI, with a rolling memory of recent messages, triggered over Telegram. The toolset already covered expense logging, calorie logging, habit logging, a general "thoughts" log, category-budget checks, to-do management via Google Tasks, Google Calendar, Spotify control, and web search via Tavily — most of this project's early feature list traces straight back to this. A same-week revision added a literature-quotes tool. No code, no Python, no Claude yet — just connected nodes in a workflow editor.
