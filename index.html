06
Under the hood

Simple to talk to.
Carefully built underneath.

Engineered to be fast, cheap, and impossible to lose data to — without you ever seeing the machinery.

Routing

Two-model pipeline

A fast, cheap model reads each message and routes intent; the stronger model runs only the handful of tools that matter. ~60% fewer tokens per reply.

Capabilities

67 tools, one brain

Every action — log an expense, query Garmin, set a reminder — is a discrete tool. Adding more is near-free; the model just picks the right one.

See all 67 tools →
Concurrency

Fully async

Chat, web dashboard and scheduler share one async event loop, so a long reply never freezes the screen or the nightly jobs.

Storage

SQLite + Sheets

Agent state in a local database; everything you'd want to read or edit by hand in a Google Sheet. Two stores, each doing what it's best at.

Resilience

Self-healing

Reconnects through network drops, a watchdog revives a frozen process, and writes queue locally if Sheets is unreachable — nothing is lost.

Cost

Cheap on purpose

Prompt caching, a tight history window, and the small model for every scheduled job keep it at roughly ₹15–25 a day, all in.

Stack — Python · Telegram Bot API · FastAPI · APScheduler · Claude (Sonnet + Haiku) · Garmin · Strava · TMDb · OpenAI voice

08
Private by design

It's yours. Entirely.

No accounts, no SaaS, no analytics, no other users. The honest picture:

🖥️

Runs on your Mac

The whole assistant lives on one machine you own. Nothing is hosted for you to depend on — or for anyone to mine.

🔒

Your data stays put

Records live in your own SQLite file and your own Google Sheet — readable, editable, deletable by you, any time.

👤

Built for exactly one person

No multi-user platform, no growth funnel. A tool sized to one life, which is the only reason it can be this personal.

What leaves your machine

Local-first isn't air-gapped. A few services see your data in transit — named plainly, nothing buried:

  • 🤖
    Anthropic API

    Every message — including logged data — transits Claude. The paid tier doesn't train on your data by default.

  • 💬
    Telegram

    Messages pass through Telegram's servers. Bot messages aren't end-to-end encrypted.

  • ⌚
    Garmin Connect

    Your fitness data lives on Garmin's servers; Jarvis fetches and caches it locally.

  • 🎙️
    OpenAI Whisper + TTSOptional

    Voice notes go out for transcription, replies for speech. Skipped entirely if no key is set.

  • 🚴
    StravaOptional

    Read-only access to your activities, feeding the marathon coach. Skipped if not connected.

A second mind for the admin of your life — so your first one is free for everything else.

One chat. One dashboard. Running quietly on a Mac in the corner, at about the price of a coffee a week.
